# 🌤️ Weather & Travel Dashboard

A modern and responsive Weather & Travel Dashboard built using **HTML, CSS, and JavaScript**. This project provides a user-friendly interface to explore weather information and travel-related details in one place.

## ✨ Features

- 🌤️ Weather information display
- 🌡️ Temperature and weather conditions
- 📍 Location-based weather information
- 🌍 Explore different locations
- ✈️ Travel-related information
- 🎨 Modern and clean dashboard UI
- 📱 Responsive design
- ⚡ Interactive user interface

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layouts, and responsive design
- **JavaScript** – Dynamic functionality and API integration

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Configure the weather API key if required.
4. Open `index.html` in your browser.
5. Explore the dashboard and check weather information.
